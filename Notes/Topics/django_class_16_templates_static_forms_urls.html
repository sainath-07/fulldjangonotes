Templates, Inheritance, Static Files, Forms & URLs

Learn how Django templates connect together and how forms, CSRF protection, static files, and named URLs work.

1. How to Create a Base Template

A base template is a common HTML file that contains the parts shared by many pages, such as the navbar, footer, CSS links, and page layout.

Usually, we create a file named base.html inside the templates folder.

project/
├── templates/
│   └── base.html
├── blog/
│   └── templates/
│       └── blog/
│           └── home.html
└── manage.py
Example: base.html
<!DOCTYPE html>
<html>
<head>
  <title>My Blog</title>
</head>
<body>

  <nav>My Blog Navbar</nav>

  {% block content %}
  {% endblock %}

  <footer>My Blog Footer</footer>

</body>
</html>
Purpose: Write common HTML only once. Child pages can reuse it instead of repeating the same code.
2. How Template Inheritance Works

Django template inheritance lets one HTML file use another HTML file as its parent.

base.html
Common layout
→
home.html
Child page
→
Final HTML page

In the child page, use:

{% extends 'base.html' %}

{% block content %}
  <h1>Welcome to Home Page</h1>
  <p>This content is specific to the home page.</p>
{% endblock %}
Remember: {% extends 'base.html' %} tells Django which parent template to use. The {% block content %} section tells Django where the child-page content should appear.
3. How to Include a Navbar

The easiest approach is to keep the navbar inside base.html. Every page that extends base.html will then receive the navbar automatically.

<!-- base.html -->

<nav class="navbar">
  <a href="{% url 'home' %}">Home</a>
  <a href="{% url 'about' %}">About</a>
</nav>

{% block content %}
{% endblock %}

This is useful because you do not need to copy the navbar into every page.

Interview tip: If a navbar appears on every page, putting it in base.html is a clean and reusable approach.
4. Templates Folder Name and DIRS in settings.py

If you create a project-level folder named templates, register that same folder in settings.py.

Folder
myproject/
├── templates/
│   └── base.html
└── manage.py
settings.py
TEMPLATES = [
    {
        ...
        'DIRS': [BASE_DIR / 'templates'],
        ...
    },
]
Important: The folder name and the folder path you register must point to the same directory. If the folder is named templates, use BASE_DIR / 'templates'.

Django then knows where to look for project-level templates such as base.html.

5. How Static Files Are Set Up

Static files are files such as CSS, JavaScript, images, fonts, and other files that are served as part of your website.

Step 1 — Create a static folder
myproject/
├── static/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── app.js
│   └── images/
│       └── logo.png
└── manage.py
Step 2 — Register the folder in settings.py

Keep the existing static URL and add STATICFILES_DIRS:

STATIC_URL = 'static/'

STATICFILES_DIRS = [
    BASE_DIR / 'static'
]
Step 3 — Load static in the HTML file

At the top of the template, use the Django static template tag:

{% load static %}

Now you can access CSS, JavaScript, and images.

<link rel="stylesheet" href="{% static 'css/style.css' %}">

<script src="{% static 'js/app.js' %}"></script>

<img src="{% static 'images/logo.png' %}" alt="Logo">
Simple flow: static/ folder → register with STATICFILES_DIRS → {% load static %} → use {% static '...' %}.
6. How to Use Forms and the CSRF Token

HTML forms send data from the browser to the server. In Django, a POST form should normally include a CSRF token.

The CSRF token helps protect a user from a type of unwanted or forged request sent from another website.

Example form
<form action="" method="POST">
  {% csrf_token %}

  <input type="text"
         name="username"
         placeholder="username" />

  <input type="password"
         name="password"
         placeholder="password" />

  <button type="submit">Login</button>
</form>
Important: Add {% csrf_token %} inside the form, especially when the form sends a POST request.

The token is generated by Django and checked when the request reaches the server.

7. How to Use the Django url Template Tag

The url template tag creates a URL using the name given to a URL pattern. This is better than hard-coding URLs throughout your HTML.

Step 1 — Give the URL a name
urlpatterns = [
    path('', views.blogHome, name="home"),
    path('about/', views.about, name="about"),
]
Step 2 — Use the same name in the template
<li>
  <a href="{% url 'home' %}">Home</a>
</li>

<li>
  <a href="{% url 'about' %}">About</a>
</li>
Rule: The value inside {% url '...' %} must match the name value in urls.py.
name="home"
in urls.py
↔
{% url 'home' %}
in template
→
Home page

Why use named URLs? If the actual path changes later, your templates can continue using the URL name instead of repeating the old path everywhere.

8. Putting Everything Together

A typical Django page can use all of these concepts together:

{% extends 'base.html' %}
{% load static %}

{% block content %}

  <link rel="stylesheet"
        href="{% static 'css/style.css' %}">

  <h1>Login</h1>

  <form method="POST">
    {% csrf_token %}

    <input type="text" name="username"
           placeholder="username">

    <input type="password" name="password"
           placeholder="password">

    <button type="submit">Login</button>
  </form>

  <a href="{% url 'home' %}">Go to Home</a>

{% endblock %}

9. Class 16 Quick Revision
  • Base template: Create base.html for common page structure.
  • Inheritance: Use {% extends 'base.html' %} to reuse the base template.
  • Blocks: Use {% block content %} where child-page content should appear.
  • Navbar: Put a common navbar in base.html so all child pages can reuse it.
  • Templates DIRS: If your folder is templates, register BASE_DIR / 'templates' in TEMPLATES['DIRS'].
  • Static files: Register STATICFILES_DIRS = [BASE_DIR / 'static'].
  • Load static: Use {% load static %} before using the static template tag.
  • Static usage: Use {% static 'css/style.css' %}, {% static 'js/app.js' %}, etc.
  • CSRF: Add {% csrf_token %} inside POST forms.
  • Named URL: Give a URL a name in urls.py, then use the same name with {% url 'home' %}.
Interview-ready idea: Django templates separate common layout from page-specific content. Template inheritance reduces repeated HTML, static-file settings manage CSS/JS/images, CSRF protects form submissions, and named URLs make navigation easier to maintain.
