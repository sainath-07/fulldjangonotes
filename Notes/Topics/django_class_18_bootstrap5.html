Django + Bootstrap 5

Class 18 — How to Add Bootstrap 5 in Django

Install django-bootstrap5, register it in Django, load Bootstrap CSS and JavaScript, and use Bootstrap classes in templates.

What are we learning?

Bootstrap is a CSS and JavaScript framework with ready-made styles and UI components. It helps us create clean and responsive pages without writing every style from scratch.

Goal: Connect Bootstrap 5 with Django and use Bootstrap classes inside Django HTML templates.
Step 1 — Run the Virtual Environment

First, activate the virtual environment of your Django project. This keeps project packages separate from other Python projects.

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
Remember: Activate your project's venv before installing the package.
Step 2 — Install Bootstrap

Install the current Django Bootstrap 5 integration package using pip.

pip install django-bootstrap5
Important spelling: Use django-bootstrap5. The word is bootstrap, not bootstarp.
Step 3 — Register Bootstrap in settings.py

Add the Django Bootstrap app to INSTALLED_APPS.

INSTALLED_APPS = [
    'django_bootstrap5',
]
Install with pip
↓
django-bootstrap5
Register in Django
↓
django_bootstrap5
Easy rule: pip uses a hyphen -; INSTALLED_APPS uses an underscore _.
Step 4 — Load Bootstrap CSS and JavaScript

Inside the Django template, load the Bootstrap template tags and then load Bootstrap CSS and JavaScript.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{% block title %}{% endblock %}</title>

    {% load django_bootstrap5 %}
    {% bootstrap_css %}
    {% bootstrap_javascript %}
</head>
<body>

    <h2>{% block heading %}{% endblock %}</h2>
    <p>{% block content %}{% endblock %}</p>

    <button type="button" class="btn btn-primary">Primary</button>
    <button type="button" class="btn btn-secondary">Secondary</button>
    <button type="button" class="btn btn-success">Success</button>
    <button type="button" class="btn btn-danger">Danger</button>
    <button type="button" class="btn btn-warning">Warning</button>
    <button type="button" class="btn btn-info">Info</button>
    <button type="button" class="btn btn-light">Light</button>
    <button type="button" class="btn btn-dark">Dark</button>
    <button type="button" class="btn btn-link">Link</button>

</body>
</html>
What do these tags do?
{% bootstrap_css %} loads Bootstrap CSS for styling.
{% bootstrap_javascript %} loads Bootstrap JavaScript for interactive Bootstrap components.
Bootstrap Button Classes

The basic Bootstrap button pattern is:

<button type="button" class="btn btn-primary">Primary</button>
Pattern: btn gives the base Bootstrap button style. The second class such as btn-primary selects the button variant.
