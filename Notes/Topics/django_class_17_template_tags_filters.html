2. {% regroup %} — Group a List by Attribute
What is regroup?

{% regroup %} takes a list of objects and creates groups based on an attribute.

Important: The data should normally be sorted by the attribute you want to group. For example, if grouping by class, sort the students by class first.
Syntax
{% regroup list by attribute as grouped_list %}
Your example
{% regroup student_list by class as grouped_students %}

<ul>
  {% for group in grouped_students %}
    <li>
      {{ group.grouper }}

      <ul>
        {% for student in group.list %}
          <li>{{ student.name }}</li>
          <li>{{ student.class }}</li>
        {% endfor %}
      </ul>
    </li>
  {% endfor %}
</ul>
How it works

Input: student_list

Class A → Students
Class B → Students
Class C → Students

group.grouper = group value   |   group.list = students in that group

Remember: group.grouper gives the grouping value, and group.list gives the objects inside that group.
3. {% widthratio %} — Simple Percentage / Ratio Calculation

{% widthratio %} calculates a ratio and scales it to a maximum width.

Syntax
{% widthratio this_value max_value max_width %}

Conceptually, Django calculates:

result ≈ (this_value ÷ max_value) × max_width
Examples from the class
progress: {% widthratio 50 500 100 %}%
progress: {% widthratio 50 100 100 %}%
progress: {% widthratio 20 100 100 %}%
50 / 500
10%
Scaled to a maximum of 100.
50 / 100
50%
Half of the maximum.
20 / 100
20%
One fifth of the maximum.
Interview tip: The third value is not always a percentage. It is the maximum width to which the ratio is scaled. Using 100 makes the result easy to read as a percentage.
Using as to save the result
{% widthratio this_value max_value max_width as width %}

<div style="width: {{ width }}%;">
  Progress
</div>
4. {% filter %} Block
What is a filter block?

The {% filter %} tag applies one or more filters to all the text inside the block.

Syntax
{% filter filter_name %}
    text
{% endfilter %}
Your examples
{% filter upper %}
this text will be converted to uppercase
{% endfilter %}

{% filter lower %}
this text will be converted to lowercase
{% endfilter %}

{% filter title %}
this text will be converted to title case
{% endfilter %}
upper
THIS TEXT WILL BE CONVERTED TO UPPERCASE
lower
this text will be converted to lowercase
title
This Text Will Be Converted To Title Case
Small correction: In the original example, the comments for lower and title say “converted to uppercase”. The actual behavior is different: lower makes text lowercase and title makes it title case.

6. Adding CSS Color to Each Route / View

CSS controls how HTML looks. In Django, a template can load a static CSS file and use a block from the base template to define page-specific CSS.

blog/templates/blog/blog.html
{% extends 'base.html' %}

{% block title %}blog title{% endblock %}

{% load static %}

{% block css %}
    <link rel="stylesheet" href="{% static 'style.css' %}">
{% endblock %}

{% block content %}
    <h1>blog html page</h1>
    ...
{% endblock %}
blog/static/style.css
h1 {
    color: red;
}
templates/base.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>
        {% block title %}base title{% endblock %}
    </title>

    {% load static %}

    {% block css %}
        <link rel="stylesheet"
              href="{% static 'css/style.css' %}">
    {% endblock %}
</head>

<body>
    {% block content %}
        <h1>base html page</h1>
    {% endblock %}
</body>
</html>
static/css/style.css
h1 {
    color: blue;
}
Important: The child template overrides the css block from the base template. Therefore, the blog page can load its own style.css.

Your base.html also contains an empty {% spaceless %} block.

{% endspaceless %}

spaceless removes whitespace between HTML tags in its block. It does not remove normal spaces inside text.

In the supplied example, the block is empty, so it does not have a useful effect. You can remove it unless you plan to place HTML inside it.
9. Interview Questions & Quick Revision
Q1. What does {% regroup %} do?

It groups objects in a list based on an attribute and stores the groups in a new template variable.

Q2. What are group.grouper and group.list?

group.grouper is the grouping value. group.list contains the objects belonging to that group.

Q3. What does {% widthratio %} do?

It calculates a ratio and scales it using the supplied maximum width.

Q4. Why use “100” as the third widthratio value?

When the maximum width is 100, the result is easy to use as a percentage-like value.

Q5. What is the difference between {% filter %} and |upper?

{% filter %} applies a filter to a whole block. |upper applies the filter to one value or expression.

Q6. Why use {% load static %}?

It loads Django's static template tag library so you can use {% static 'file-path' %} to reference static files.

Q7. How can a child template use page-specific CSS?

The base template can provide a {% block css %}, and the child template can override that block with its own stylesheet link.
