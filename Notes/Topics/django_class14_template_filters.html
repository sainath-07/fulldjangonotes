Template Filters

Learn how Django filters transform and format values while rendering templates.

1. What is a Template Filter?

A template filter changes or formats a value when it is displayed in a Django template.

{{ value|filter }}
{{ value|filter:"argument" }}
Value
|
Filter
→
Displayed result
Easy memory: The pipe | means “apply this filter to the value”. Filters can also be chained.
{{ post.title|lower|capfirst }}
2. Project Setup

views.py

from django.shortcuts import render
from datetime import datetime

def blogPage(request):
    post = {
        'title': "my template post",
        'description': 'django is high level python web framework',
        'author': None,
        'created_at': datetime(2026, 8, 30),
        'comments_count': 3,
        'tags': ['django', 'python', 'web development'],
        'price': 100,
        'number': 9
    }
    return render(request, 'blog/blog.html', {'post': post})

blog/urls.py

from django.urls import path
from . import views

urlpatterns = [
    path('', views.blogPage, name='blogPage')
]

innerProject/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('blog.urls'))
]
Flow: URL → view → post data → template → filter → browser.
3. Text Filters

upperlowertitlecapfirsttruncatecharstruncatewordslinebreaks

FilterExampleMeaning
upper{{ post.title|upper }}Converts text to uppercase.
lower{{ post.title|lower }}Converts text to lowercase.
capfirst{{ post.title|capfirst }}Capitalizes the first character.
title{{ post.title|title }}Converts words toward title case.
truncatechars{{ post.title|truncatechars:8 }}Shortens by character count.
truncatewords{{ post.description|truncatewords:4 }}Shortens by word count.
linebreaks{{ post.description|linebreaks }}Converts line breaks to suitable HTML paragraphs/line breaks.
Remember: chars = characters; words = words.
4. Number Filters

add

{{ post.price|add:5 }}
100 + 5 → 105

divisibleby

Your example also uses divisibleby to test even/odd values.

{% if post.number|divisibleby:2 %}
    {{ post.number }} is Even number
{% else %}
    {{ post.number }} is Odd number
{% endif %}
9 → 9 is Odd number
Important correction: Django has add and divisibleby as built-in filters, but there is no standard built-in divideby filter. Do division in Python or use an appropriate custom filter.
5. List Filters
tags = ['django', 'python', 'web development']
FilterSyntaxResult
first{{ post.tags|first }}django
last{{ post.tags|last }}web development
length{{ post.tags|length }}3
slice{{ post.tags|slice:":2" }}First two items
join{{ post.tags|join:", " }}django, python, web development
Memory: first/last pick items, length counts, slice takes a part, and join combines items into text.
6. yesno & pluralize

yesno

{{ post.author|yesno:"Yes,No,Maybe" }}

For author = None, the third choice is returned:

Maybe
The choices correspond to true, false, and None.

pluralize

Comments: {{ post.comments_count }} Comment{{ post.comments_count|pluralize }}
For 3 → Comments: 3 Comments
For 1, 1|pluralize returns an empty suffix, giving “1 Comment”.
7. Date & Time Filters
created_at = datetime(2026, 8, 30)

date

{{ post.created_at|date:"D d M Y" }}

Formats the date using Django date format characters.

time

{{ post.created_at|time:"H:i" }}

Formats the time portion.

timesince

{{ post.created_at|timesince }}

Shows elapsed time since a date/time.

timeuntil

{{ future_date|timeuntil }}

Shows remaining time until a future date.

Correction: The correct filter is timeuntil, not timeunitl.
8. Encoding & Formatting

urlencode

{{ post.title|urlencode }}

Encodes a value for safe representation in a URL.

floatformat

{{ 123.455|floatformat:2 }}
Example display → 123.46
Memory: urlencode → URLs. floatformat → decimal display.
9. Common Mistakes
Misspelling filters
Use timeuntil, not timeunitl.
Assuming divideby exists
There is no standard built-in divideby.
Confusing characters and words
truncatechars and truncatewords count different things.
Complex calculations in templates
Prefer Python code for complex business logic.
