Retrieve Data from a Database Table

Learn how to fetch records from a Django database and display them in an HTML template.

1. Complete Process

When you want to display database data on a webpage, follow these five main steps:

  1. Define your model in models.py.
  2. Create and apply migrations.
  3. Fetch data from the database using Django ORM.
  4. Send the data to the template using the view context.
  5. Display the data in the HTML template using Django Template Language.
Simple idea: Model → Database → View → Context → Template → Browser

2. Define the Model

The model describes the structure of the database table. Here we create a Student model with name, age, and email.

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()
    email = models.EmailField(unique=True)

    def __str__(self):
        return self.name
Important correction: The special method is __str__(), with two underscores before and after str. It should not be __str___.

3. Run Migrations

After defining or changing a model, Django needs to create or update the database table.

For one specific app
python manage.py makemigrations appname
Apply the migration to the database
python manage.py migrate
Remember: makemigrations creates migration files. migrate applies those changes to the database.

4. Fetch Data in views.py

Import the model and use Django ORM to retrieve all Student records.

from django.shortcuts import render
from .models import Student

# Create your views here.
def blogHome(request):
    students = Student.objects.all()
    return render(
        request,
        'blog/blog.html',
        {'student_list': students}
    )
Why use context? The context dictionary sends Python data from the view to the HTML template. Here, student_list is the template variable and students is the QuerySet.

5. Display Data in HTML

Place the template inside blog/templates/blog/blog.html. Use a loop to display each Student object.

<!doctype html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Blog title</title>
</head>
<body>
  <h1>Welcome to blog page</h1>

  {% if student_list %}
  <table border="1">
    <thead>
      <tr>
        <th>Name</th>
        <th>Age</th>
        <th>Email</th>
      </tr>
    </thead>
    <tbody>
      {% for student in student_list %}
      <tr>
        <td>{{ student.name }}</td>
        <td>{{ student.age }}</td>
        <td>{{ student.email }}</td>
      </tr>
      {% endfor %}
    </tbody>
  </table>
  {% endif %}
</body>
</html>
How the loop works: {% for student in student_list %} takes one Student object at a time. Then {{ student.name }}, {{ student.age }}, and {{ student.email }} read its fields.

6. Connect the URLs

blog/urls.py
from . import views
from django.urls import path

urlpatterns = [
    path('', views.blogHome, name='blogHome')
]
Project urls.py
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('blog.urls'))
]
URL flow: The project URL includes blog.urls. The empty path then calls blogHome.

9. Interview Tips

  • Where is the database structure defined? In models.py.
  • What does makemigrations do? It creates migration files based on model changes.
  • What does migrate do? It applies migrations to the database.
  • How do you retrieve all records? Use Student.objects.all().
  • How does data reach the template? Through the context dictionary passed to render().
  • How does the template access a model field? With syntax such as {{ student.name }}.
  • Why use {% if student_list %}? It checks whether the context variable contains data before displaying the table.
