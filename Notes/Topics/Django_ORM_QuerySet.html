Django ORM QuerySet

Learn how to fetch database records using simple Python code.

1. What is a QuerySet?

A QuerySet is a collection of database records returned by a Django ORM query.

Simple definition: QuerySet = a collection of rows/records returned from a database query.

For example:

students = Student.objects.all()

Here, students is a QuerySet containing the matching Student records.

Interview tip: A QuerySet is not just a Python list. It is a Django object representing a collection of database results and supports further ORM operations.

2. Why is a QuerySet Required?

Without an ORM, you would commonly write SQL directly:

SELECT * FROM student WHERE age = 22;

With Django ORM, you can express the same idea using Python-style code:

Student.objects.filter(age=22)
Main benefit: For common database operations, you can work with Python objects and Django ORM instead of manually writing SQL queries.

4. all() — Fetch All Records

all() returns a QuerySet containing all records from the model's table.

from blog.models import Student students = Student.objects.all() print(students) exit()
Print each record using a for loop
from blog.models import Student students = Student.objects.all() for s in students: print(s.name, s.age)
Correction to remember: If your variable is named students, use for s in students:, not for s in Students:. Python variable names are case-sensitive.

5. get() — Fetch One Record

get() is used when you expect exactly one record.

from blog.models import Student student = Student.objects.get(id=1) print(student)
Important: get() raises an error if no record matches (DoesNotExist) or if more than one record matches (MultipleObjectsReturned).
When should you use get()?
  • Use it when the lookup should identify one unique record.
  • A primary key such as id=1 is a common example.
  • Do not use get() when multiple records are expected.
Interview tip: get() returns a single model instance, while filter() returns a QuerySet.

6. filter() — Fetch Records with a Condition

filter() returns a QuerySet containing all records that match the given conditions.

Example 1 — Exact match
from blog.models import Student students = Student.objects.filter(age=22) print(students)
Example 2 — Greater than
students = Student.objects.filter(age__gt=30) print(students)
Key point: filter() can return zero, one, or many records. It does not raise MultipleObjectsReturned simply because multiple records match.

10. Interview Tips & Quick Revision

  • A QuerySet represents a collection of database results.
  • Student.objects.all() fetches all records.
  • Student.objects.get(id=1) expects exactly one record.
  • Student.objects.filter(age=22) returns matching records.
  • QuerySets can be further filtered, ordered, sliced, and combined.
  • Django ORM generates database queries for you; it does not mean SQL is never involved.
Interview question: “What is the difference between get() and filter()?”
Answer: get() returns one object and expects exactly one match. filter() returns a QuerySet and can contain zero, one, or many matches.
