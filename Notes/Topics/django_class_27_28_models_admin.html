Creating Multiple Models

A Django app can contain many models. Each model usually represents one type of data stored in the database.

models.py
from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()
    email = models.EmailField(unique=True)

    def __str__(self):
        return self.name


class Profile(models.Model):
    bio = models.TextField(max_length=1000)
    location = models.CharField(max_length=200)
    birth_date = models.DateField(null=True)

    def __str__(self):
        return self.bio
Important correction: models.CharField() needs max_length. So use location = models.CharField(max_length=200) instead of the incomplete models.CharField().
Why use __str__()?
Django Admin needs a readable label for an object. return self.name makes a Student appear by name instead of something like Student object (1). If returning a number, use return str(self.age).

Registering Models in admin.py of app folder

A model should be registered with Django Admin before you manage its records through the admin site. 

from django.contrib import admin
from .models import Student
from .models import Profile

# Default registration
admin.site.register(Profile)

# Customized registration
@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):
    list_display = ('name', 'age', 'email')
    search_fields = ('name', 'age')
    list_filter = ('age', 'name')
    ordering = ('name',)
Do not register Student twice. If you use @admin.register(Student), do not also use admin.site.register(Student).
Simple registration
admin.site.register(Profile)
Good when default admin behavior is enough.
Custom registration
@admin.register(Student)
Good when you need admin customization.

Admin Search & Filters
Search

search_fields adds fields to the admin search box. 

search_fields = ('name', 'age')
Practical tip: Text fields such as name and email are common search choices. If your project needs age search, you can keep age.
Filters

list_filter adds controls that help narrow the list. 

list_filter = ('age', 'name')
Easy memory trick: Search is for finding something you know. Filters are for narrowing a list by values.
Admin Ordering

ordering controls the default sort order.

ordering = ('name',)
Ascending
('name',) → A to Z
Descending
('-name',) → Z to A
Complete admin.py Example
from django.contrib import admin
from .models import Student, Profile

admin.site.register(Profile)

@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):
    list_display = ('name', 'age', 'email')
    search_fields = ('name', 'age')
    list_filter = ('age', 'name')
    ordering = ('name',)
Profile uses the default admin page. Student uses a customized admin list page.
Common Mistakes
Missing max_length: CharField() needs max_length.
Registering twice: Do not register Student with both registration styles.
Skipping migrations: Run makemigrations and migrate after model changes.
Wrong __str__ return: __str__() must return a string.
