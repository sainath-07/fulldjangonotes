Retrieving, Ordering & Selecting Data

Learn how to get database records, sort them, add conditions, select fields, and count records using simple Django ORM methods.

1. Retrieving Data from the Database

In Django, we usually use the ORM instead of writing SQL directly. A model manager such as Student.objects helps us ask the database for records.

Remember: Methods such as all(), filter(), and exclude() commonly return a QuerySet. Methods such as first() and last() return one object or None.
2. Ordering Data

order_by() sorts the records.

from appname.models import Student

students = Student.objects.all().order_by('name')
print(students)

Ascending order: use the field name without -.

students = Student.objects.all().order_by('name')

Descending order: put - before the field name.

students = Student.objects.all().order_by('-name')
name → A to Z / ascending
-name → Z to A / descending
3. Chaining QuerySet Methods

Chaining means using more than one ORM method in the same query. You can filter records and then order the matching records.

students = Student.objects.filter(age=18).order_by('name')
print(students)

Simple meaning: First find students whose age is 18, then sort those students by name.
4. exclude() — Opposite of filter()

exclude() removes records that match the condition. In simple words, it gives you the records that do not match the condition.

students = Student.objects.exclude(age=22)
print(students)
filter(age=22)
Give students whose age is 22.
exclude(age=22)
Give students whose age is not 22.
Memory trick: filter() = keep matching records. exclude() = remove matching records.
5. values() and values_list()
values() — dictionary-like results

values() lets you select only the fields you need. Each result is represented as a dictionary-like object.

students = Student.objects.values('name', 'age')
print(students)

Conceptually, the result looks like:

{'name': 'Rahul', 'age': 18}
{'name': 'Priya', 'age': 20}
values_list() — tuple/list-like results

values_list() returns field values as tuples by default. With flat=True and one field, you get a simple sequence of values.

students = Student.objects.values_list('name', flat=True)
print(students)

Conceptually:

['Rahul', 'Priya', 'Amit']

Important: In your original example, use the same model name consistently, for example Student.objects if your model is named Student.
6. first() and last()

Use these methods when you want one record from the beginning or end of the current QuerySet.

student = Student.objects.first()
student = Student.objects.last()

Important: If the QuerySet is empty, first() and last() return None.
7. count() — Total Number of Records

count() returns the number of records in the QuerySet.

students = Student.objects.count()
print(students)

If there are 50 students, count() returns:

50
Use case: count() is useful when you need the total number of matching records, such as the number of active users or students in a class.
