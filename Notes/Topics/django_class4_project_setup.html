CLASS 4

Django Project Setup

Learn how to check Django, create a project, understand its structure, and run the development server.

1. What We Will Learn

Django project setup flow

When starting a Django project, follow this simple order:

Check Django ↓ Create Django project ↓ Enter the project folder ↓ Run the development server ↓ Open the project in your browser
Goal: By the end, you should be able to create a Django project and see the Django welcome page in your browser.

2. Check Django Installation

Step 1 — Check Django

Before creating a Django project, first check whether Django is installed.

django-admin --version

If Django is installed correctly, the command displays the installed Django version.

Tip: If the command is not recognized, make sure Django is installed in the Python environment you are currently using and that the environment is activated when required.

3. Create a Django Project

Step 2 — Create the project

Use the following command:

django-admin startproject projectname

Replace projectname with the name you want for your project.

Example:
django-admin startproject mysite

After running the command, Django creates a folder containing the initial project files.

Command django-admin startproject mysite ↓ Django creates ↓ mysite/
What does this command mean?
PartMeaning
django-adminDjango's command-line utility.
startprojectTells Django to create a new project.
projectnameThe name you choose for your Django project.

4. Django Project Structure

Example structure

If you create a project named mysite, Django creates a structure similar to this:

mysite/ │ ├── manage.py │ └── mysite/ ├── __init__.py ├── settings.py ├── urls.py ├── asgi.py └── wsgi.py
What are these files?
FileSimple meaning
manage.pyA command-line helper used to work with your Django project.
settings.pyContains the main project configuration.
urls.pyDefines URL routes for the project.
asgi.pyEntry point for ASGI-compatible servers.
wsgi.pyEntry point for WSGI-compatible servers.
__init__.pyMarks the directory as a Python package and can contain package initialization code.
Beginner focus: For now, remember manage.py, settings.py, and urls.py. You will use these frequently as you learn Django.

5. Run the Django Project

Step 3 — Go to the correct folder

After creating the project, go to the folder that contains manage.py.

mysite/ │ ├── manage.py ← run the command from here └── mysite/

For example, if your terminal is outside the project folder:

cd mysite
Step 4 — Start the development server

Run:

python manage.py runserver

Django starts its development server. You should see a message containing a local address such as:

Starting development server at http://127.0.0.1:8000/

Open that address in your browser.

Default port: Django's development server uses port 8000 by default.
Complete flow
django-admin --version django-admin startproject mysite cd mysite python manage.py runserver

6. Django Project Name Rules

Choose the project name carefully

A Django project name is used as a Python package name, so it should follow Python identifier rules.

Good names ✅

mysite
my_project
django_project
employee_management
Avoid ❌

my-project
my project
123project
project-name
Simple rule: Use letters, numbers, and underscores. Do not use hyphens (-) or spaces. Also, avoid starting the name with a number.
Interview Tip 💡

If asked how to create a Django project, remember: django-admin startproject projectname. Then enter the folder containing manage.py and run python manage.py runserver.
