Django Admin

Learn how to prepare the project, create a superuser, open Django Admin, and manage database data without writing SQL queries.

1. What is Django Admin?

Django Admin is a ready-made dashboard provided by Django. It helps developers and administrators manage database records through a web page.

Simple idea: Instead of writing SQL or ORM queries every time, you can use the Admin page to add, view, update, and delete records.

2. Prepare the Project with Migration

Before using your model data in Admin, create the database tables by running migrations.

Step 1 — Create migration files
python manage.py makemigrations

This checks your model changes and creates migration files.

Step 2 — Apply migrations
python manage.py migrate

This applies the migrations and creates/updates the required database tables.

Remember: makemigrations creates migration instructions. migrate applies those instructions to the database.
3. Create a Superuser Account

A superuser is an account with full access to the Django Admin site. The username and password you create for this account are used to log in.

Important: The superuser credentials are for the Django Admin login. Keep the password private and use a strong password.
Create the account
python manage.py createsuperuser

Django will ask you for:

  1. Username
  2. Email address
  3. Password

4. Access the Django Admin Page

After creating the superuser, start the Django development server and open the Admin URL in your browser.

python manage.py runserver

Then visit:

/admin/

For a local development server, this is commonly:

http://127.0.0.1:8000/admin/

Enter the username and password of the superuser you created.

5. Managing Data Through Django Admin

After logging in, the Admin dashboard can show the models that have been registered with Django Admin. From the model page, you can manage records.

Adding data

Click the add option, enter field values, and save the record.

Updating data

Open an existing record, change its values, and save it.

Deleting data

Select a record and use the delete option when you no longer need it.

Managing users and groups

A superuser can also manage users and groups from the Admin site, when those features are available and registered.

Why is this useful? Django Admin gives you a ready-made management interface, so you do not need to build a separate dashboard for basic internal database management.

7. Interview Tips
Interview Tip: Be able to explain the difference between makemigrations and migrate.
  • What is Django Admin? A built-in web interface for managing application data.
  • What is a superuser? A Django user account with full Admin permissions.
  • Which command creates a superuser? python manage.py createsuperuser
  • Where is Admin usually accessed? Through the /admin/ URL.
  • Why use Admin? It provides a ready-made interface for common data management tasks.
